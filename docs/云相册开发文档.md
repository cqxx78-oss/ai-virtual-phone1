# 云相册（Cloud Album）开发与技术规范文档

## 一、项目概述
- **APP 名称**：云相册
- **应用类型**：单文件自定义 APP（编译安装至宿主虚拟手机系统）
- **默认后端 API 基地址**：`https://api.p2ino.info:8443`（支持在前端设置中修改并持久化到 IndexedDB）
- **设计风格**：瑞士 Spa 级极简主义 / 纯 SVG 矢量图标系统 / 0 Emoji / 石墨冷灰与微磨砂亚克力配色 / 响应式呼吸感间距

---

## 二、后端 API 接口协议

| 动作 | 方法 | 路径 | 参数 / Body | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| **获取照片列表** | `GET` | `/list` | 无 | 返回 `{ photos: [{ id, filename, name, categoryId, createdAt }] }` |
| **获取分类列表** | `GET` | `/categories` | 无 | 返回 `{ categories: [{ id, name }] }` |
| **创建相册分类** | `POST` | `/category` | `{ name: string }` | 返回 `{ id, name }` |
| **上传照片** | `POST` | `/upload` | `FormData (photo: File)` | 返回 `{ success: true, id, filename }` |
| **修改照片分类** | `PUT` | `/photo/:id/category` | `{ categoryId: number | null }` | 移入相册、回收站或设为未分组 |
| **WebP 压缩图** | `GET` | `/image/:id` | `?width=1200&format=webp&quality=85` | 获取高效压缩动态转码图 |
| **原图直链** | `GET` | `/raw/:filename` | 无 | 获取上传时的无损原始文件 |
| **彻底硬删除** | `DELETE` | `/delete/:id` | 无 | 从服务器硬盘永久抹除文件（支持多路由降级重试） |

## 三、已实现的核心交互与架构设计

### 1. 分类管理与软删除回收站
- 顶部支持横向平滑滚动的分类栏（全部、未分组、自定义分类、回收站）；
- 应用初始化时自动调用 `ensureTrashCategory` 检索或创建系统专属「回收站」分类；
- 支持移入回收站（软删除）与从回收站还原（归位到未分组）。

### 2. 批量多图直传
- 顶部导航栏直传按钮 + 右下角悬浮 FAB 按钮，同时绑定原生文件选择器（`multiple` 多选）；
- 顶部实时展示分片上传进度条（`正在上传 3/12...`）；
- 若在特定相册分类下上传，上传完毕后自动将新照片关联至当前相册。

### 3. 画廊级大图预览（Lightbox）
- **触控手势滑动**：大图预览区支持原生 Touch 左右跟手拖拽与惯性滑动切图，伴随阻尼透明度淡入淡出动画；
- **左右悬浮切图**：图片两侧配备微透磨砂浮动导航箭头；
- **序号与元数据联动**：顶部实时计算当前索引（如 `3 / 18`），并在删除/切图后自动平滑更新；
- **键盘支持**：支持电脑键盘左右箭头（`←` / `→`）切图与 `Esc` 退出。

### 4. 链接复制与真·本地无损下载
- **复制 WebP 链接**：精简操作栏，一键复制高压缩比 WebP 动态图 URL，内置 `navigator.clipboard` 与隐藏 `execCommand` 多级容错；
- **下载原图**：严格锁定无损原图直链，通过前端发起 `fetch` 获取二进制同源 Blob 触发下载，彻底解决移动端跨域导致的直接网页跳转和画面撑大问题。

### 5. 全局模态交互规范
- 所有危险/确认操作（移入回收站、从回收站恢复、彻底删除）均统一接入石墨冷灰风格的亚克力模态确认框（Confirm Modal），彻底杜绝原生粗糙的 `alert/confirm` 阻塞。

## 四、后续迭代路线（Roadmap）

1. **相册分组管理**：长按分类标签唤起重命名、删除分组（及其级联照片处理策略）；
2. **批量管理模式**：长按列表进入多选批量模式，支持批量下载原图、批量迁移分组与批量移入回收站；
3. **多维排序与过滤**：支持按上传时间正序/倒序、文件体积筛选，以及关键词实时搜索；
4. **离线与弱网缓存**：结合 IndexedDB 缓存缩略图，提升弱网秒开体验。
